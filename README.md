I am sorry I watered your plastic plant for three weeks while the real fern dried out on the shelf beside it.
I have learned that green is not the same as alive, so from now on I will check the soil before I water anything.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the two-line apology to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). It runs with Python 3.13
and the standard library only, and writes the same bytes on every run.
